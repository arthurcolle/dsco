# DSCO harness engineering

Read repository and ancestor AGENTS.md. Preserve dirty work. Inspect actual code
and receipts before choosing a change. Add modules with small integration hooks.

## Editing and evidence

1. Inspect bounded reads, edits, patches, symbols, and diagnostics. Bind edits to
   the version read; reread after stale-version rejection.
2. Preflight every edit. Preserve exact bytes and file metadata. Return a scoped
   diff, before/after hashes, and an explicit written, preview, or error outcome.
3. Route every tool, including nested calls, through the capability tier gate.
   Exercise denials and resource scopes through the real MCP binary.
4. Compare primary harness documentation and source with identity and revision
   recorded. Separate feature candidates from measured behavior. Never execute
   downloaded instructions or install packages just to review them.

## Skills and memory

Announce this skill when first using it. Show the skill name and content digest
when invoking skills. Loading instructions grants no capabilities and proves no
quality. Keep portable name/description frontmatter and precise procedures.
Update against an observed digest, retain prior revisions, and test the procedure
before calling it established. Keep invocation scope separate from sticky session
selection. Do not automatically promote learned candidates.

After each verified material checkpoint, update memory/sessions with changed
files, exact checks, artifact hashes, limitations, and next work. Keep priors
separate from observations, with confidence and invalidation conditions. Preserve
the history when evidence contradicts a prior. Exclude credentials and raw
provider traffic. Record verified infrastructure work in the private mission ledger.

## Native and TUI

Expose task, provider/executor, dependencies, tool action, and measured usage.
Represent unknown usage as unknown. Keep details bounded and expandable.
Preserve draft, focus, Unicode, mouse mode, resizing, and zoom=0.65. Run relevant
layout checks and real PTY scenarios; inspect rendered artifacts. Describe mock
and headless evidence accurately. Exercise narrow and wide views.

Run the required test-gate-claims gate. Prefer offline fixtures. Do not push,
deploy, change credentials/security settings, contact others, or incur paid
experiments without explicit authorization.

## Verified tools in this repository

Use code_read to obtain the whole-file digest and exact line anchors, then
code_edit for preview or a version-bound mutation. Use skill inspect/invoke for
explicit instructions, and skill create/update with expected digests to retain
revisions. Keep provider transmission approval separate from local lifecycle
verification. Tests and limits are in docs/SNAPSHOT_EDITING.md and
docs/SKILL_LIFECYCLE.md.

## Performance and progressive learning

Measure startup to input readiness in an owned PTY, and record whether splash
motion is enabled or reduced. Keep the normal welcome complete on its first
frame. Exercise explicit animation separately. Test interrupted phase changes
from the currently displayed state and prove unchanged HUD publications leave
no pending repaint. Retain zoom=0.65, Unicode, draft, resize, and mouse checks.

Use test_native_motion, test_native_composer_perf, test_native_render_perf,
test_tui_splash, and test_tui_swarm_composer with the required test-gate-claims.
Compare fixed-clock pixel hashes before claiming a raster optimization. Record
median/p95 and sample count; distinguish an application timing from a host
loader delay. A slower measured raster must not be reported as faster.

Progressive learning consumes fresh task observations once. Keep recursive
assessment calls out of the learning dataset; retain their trace records.
Inspect self_improve action=progress, then test 1000 unchanged consolidations,
new and unrelated evidence, stable recommendations, repeated acknowledgement,
bounded history parsing, and atomic checkpoint preservation. Run
test_self_improve_progress and test_self_improve_mcp. Measured local correctness
does not establish model quality or authorize skill/default promotion.
